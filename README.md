<p align="center">An AI app builder for non-technical people. Describe what you want, get a working app with a live preview.</p>

## Status

Early development. Phase 1 generates frontend-only web apps (React, Vite, Tailwind CSS, shadcn/ui).

## Brand

Logo files live in [`assets/brand/`](assets/brand):

| File | Use |
|---|---|
| `buildinio-logo-light-bg.svg` / `.png` | Logo with name, for light backgrounds |
| `buildinio-logo-dark-bg.svg` / `.png` | Logo with name, for dark backgrounds |
| `buildinio-mark.svg` / `.png` | Triangle mark only, transparent |
| `github-avatar-light.png` / `github-avatar-dark.png` | 512×512 avatars |

- **Colors (mark gradient, top-left to bottom-right):** `#FFB21E` `#FF4F6D` `#E23FA8` `#7A5BFF` `#2E9BFF`
- **Wordmark:** Gabarito Bold, letter spacing −3%, text `#17151F` on light and `#FFFFFF` on dark. The name in the logo files is outlined, so no font is needed to display them.
